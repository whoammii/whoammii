## About

I work where **frontend development, design and motion** meet. Over the last 6+ years, I have built interfaces, supported existing products, added new functionality and created visual content.

I care about hierarchy, typography, responsive behavior and the small interactions that give a product its character. I also use AI tools to automate repetitive work and explore better ways to build.
